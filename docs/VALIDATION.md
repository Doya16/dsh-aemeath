# v1.0.0 首个版本

完整程序与爱弥斯 DeepSeek 桌宠完整包 v1.0.0 相同（见 [desktop/UPSTREAM.json](../desktop/UPSTREAM.json)），并做了插件市场版改动：数据目录在 Harness 数据目录下的 `aemeath-market`，由插件下载、校验和启动，不需要单独的连接插件。

- 三套表情预设（鸭牌、雾雪、Stephen），90 条带字幕的爱弥斯语音；呜哇小站表情包压缩包导入、按画师和合集分组、删除合集；关于与致谢。
- 插件入口使用自己的样式前缀，位置高于其他桌宠插件的入口，同时启用时不会重叠。
- 一键更新使用爱弥斯 DeepSeek 系列专用的发布密钥，不接受其他产品的签名。
